# 프리랜서 정산노트

프리랜서를 위한 3.3% 원천징수 계산기 + 수입·입금 관리 웹앱(PWA).

## 기능

- **3.3% 계산기** — 계약금액 → 실수령액, 실수령액 → 계약금액 역산
- **수입 기록장** — 월별·연별 합계, 거래처별 수입 비중
- **입금 관리** — 입금 예정일 D-day, 연체 경고, 원탭 입금 완료 처리
- **내보내기·백업** — 엑셀(CSV) 내보내기, JSON 백업/복원
- **PWA** — 홈 화면 설치, 오프라인 사용

## 계산 기준

- 소득세: 지급액 × 3%, 10원 미만 절사
- 지방소득세: 소득세 × 10%, 10원 미만 절사

참고용 계산이며 실제 세액은 지급처 처리 방식에 따라 다를 수 있습니다.

## 데이터 저장

모든 기록은 사용하는 기기의 브라우저(localStorage)에만 저장되며 서버로 전송되지 않습니다.
기기를 바꾸기 전에는 앱의 **백업 파일 저장** 기능으로 백업하세요.

## 로컬 실행

```bash
python -m http.server 5173
```

브라우저에서 http://localhost:5173 접속.

## 배포 시 주의

`index.html` 등 앱 파일을 수정해 배포할 때는 `sw.js`의 `VERSION` 값을 올려야 사용자 기기의 이전 캐시가 정리됩니다.
